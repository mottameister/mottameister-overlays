# Twitch Reward Icons

Icones para recompensas da Twitch do `@mottameister`.

## Arquivos

Cada recompensa tem PNGs em `28x28`, `56x56` e `112x112` dentro de `png/`.

- `destacar-mensagem`
- `emote-inscrito-aleatorio`
- `mensagem-inscritos`
- `escolher-emote`
- `modificar-emote`

`preview.png` mostra o kit completo.

## Regenerar

Na raiz do repo:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\generate-twitch-reward-icons.ps1
```
