# Penas De Coruja

Currency visual do canal para a Twitch.

## Arquivos

- `source/pena.png`: imagem fonte original.
- `png/penas-de-coruja-28.png`: `28x28`.
- `png/penas-de-coruja-56.png`: `56x56`.
- `png/penas-de-coruja-112.png`: `112x112`.
- `preview.png`: preview em fundo escuro.

## Regenerar

Na raiz do repo:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\generate-twitch-currency.ps1
```
